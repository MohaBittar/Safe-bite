# SafeBite - Allergy & G6PD Safety Scanner

An AI-powered food safety web app that helps people with allergies and G6PD deficiency stay safe by scanning food ingredients.

## Features

- **AI Image Scanner** - Upload photos of food ingredients for instant analysis
- **OCR Text Extraction** - Automatically reads ingredient labels from images
- **Manual Input** - Type ingredients directly for quick checking
- **G6PD Deficiency Support** - Comprehensive database of trigger foods
- **10 Allergy Types** - Peanut, Tree Nut, Milk, Egg, Wheat, Soy, Shellfish, Fish, Sesame, Sulfite
- **Safety Ratings** - Safe, May Affect, Dangerous, Could Cause Severe Reaction
- **User Profiles** - Save your allergy/condition selections
- **Scan History** - Track all your previous scans
- **Admin Panel** - Manage users and view statistics
- **Firebase Integration** - Auth, Firestore database, real-time sync
- **Google & Email Auth** - Sign in with Google or email/password
- **Mobile Responsive** - Works perfectly on phones, tablets, and desktops

## Technologies

- HTML5, CSS3, JavaScript (ES6+)
- Firebase (Auth, Firestore, Hosting)
- OCR.space API (text extraction)
- Font Awesome icons
- Inter font (Google Fonts)

## Setup

1. Clone this repository
2. Open `index.html` in a browser, or deploy to Firebase Hosting:

```bash
firebase login
firebase init
firebase deploy
```
